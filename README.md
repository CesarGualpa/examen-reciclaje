# Examen Final - Sistema de Puntos de Reciclaje Urbano

Aplicación full stack desarrollada con Spring Boot, PostgreSQL y React.

## Proyectos

- `reciclaje-api`: Backend REST con Spring Boot.
- `reciclaje-web`: Frontend con React y Vite.

## Funcionalidad

- Registrar puntos de reciclaje.
- Consultar todos los puntos registrados.
- Persistir información en PostgreSQL.
- Actualizar automáticamente el listado después de registrar.
